# תמונות פרויקטים

האתר טוען את התמונות מנתיבים מקומיים בקובץ זה.
שמרי את 4 התמונות **בשמות הקבצים המדויקים** הבאים:

```
public/images/projects/
├── domus-tlv.jpg          ← מלון Domus תל אביב (השלט הירוק)
├── tzuriel-maalot.jpg     ← מתחם צוריאל מעלות-תרשיחא (רנדר אדריכלי)
├── israel-rail.jpg        ← רכבת ישראל (הרכבת האדומה)
└── hayarkon-hotel.jpg     ← מלון הירקון (המבנה הרב-קומתי)
```

## המלצות לתמונות
- יחס מועדף: 16:11 (אופקי) — אם התמונה אחרת, `next/image` יחתוך מהמרכז בלי לעוות
- רזולוציה מינימלית: 1600×1100
- פורמט: JPG (אפשר גם WebP — שם הקובץ יישאר `.jpg`)
- משקל: עד 500KB לכל תמונה

ברגע שתחליפי את ה-placeholders האלה בקבצים האמיתיים, האתר יציג אוטומטית.
לעריכת הטקסטים של הפרויקטים — `lib/constants.ts`, מערך `PROJECTS`.
