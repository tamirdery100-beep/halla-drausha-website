# תמונות נכסים

## תמונת הפורטרט של האלה
שמרו את התמונה בנתיב הבא **בדיוק**:

```
public/images/hala-portrait.jpg
```

המלצות לתמונה:
- יחס תמונה: 4:5 אנכי (אחרת `next/image` ימלא אוטומטית)
- רזולוציה מינימלית: 800×1000
- פורמט: JPG (אפשר גם WebP — שם הקובץ יישאר `.jpg`)
- משקל: עד 500KB

הקומפוננטה משתמשת בפילטר עיצובי (mix-blend-luminosity + שכבת כחול עמוק)
שמלכד את התמונה לפלטה של האתר. ב-hover התמונה חוזרת לצבעים מקוריים.
